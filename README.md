# AI Spend Audit Tool

A web application that helps startups analyze and optimize their AI tool spending.

## Features

- AI spending audit
- Savings recommendations
- Shareable audit reports
- AI-generated summaries

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase

## Run Locally

```bash
npm install
npm run dev
